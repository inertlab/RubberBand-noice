# Rhythm Game For Mac
noice (internal name Rubber Band), is a game a la Rock Band developed entirely with Mac native frameworks and as of version 1.3, it is also entirely written in Swift

## Setup
noice uses PhaseShift folder format for songs. Other formats can be easily converted using Onyx

To add songs to the library, place song folders in ~/Music/noice/

That's it.

Other than ogg files, you can use any Mac native format like m4a, aac, mp3 etc. These have the advantage of hardware level decoding and provide better performance in game

## Dependencies
There are 2 packages required - VorbisFile for decoding Ogg files and SwiftRPC for Discord Rich Presence. SwiftRPC is not vital to the game and can be omitted
